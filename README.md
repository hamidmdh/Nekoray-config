# NekoRay Auto-Connect

اسکریپت پایتون برای **پیدا کردن خودکار کانفیگ سالم در NekoRay** و **اتصال به آن**.

وقتی در NekoRay ده‌ها یا صدها کانفیگ (و سابسکریپشن) دارید و نمی‌دانید کدام‌شان کار می‌کند، کافی است این اسکریپت را اجرا کنید: همه‌ی کانفیگ‌ها را واقعاً تست می‌کند، اولین/سریع‌ترین کانفیگ سالم را انتخاب می‌کند، NekoRay را روی آن تنظیم می‌کند و برنامه را باز می‌کند.

---

## امکانات

- تست واقعی اینترنت از داخل هر کانفیگ (نه فقط پینگ TCP)
- پشتیبانی از پروتکل‌های `vless`، `vmess`، `trojan` و `shadowsocks`
- پشتیبانی از `TLS`، `Reality`، `uTLS`، `WS`، `gRPC`، `HTTP/2`
- تست هم‌زمان چند کانفیگ (پیش‌فرض ۱۶ تست موازی)
- حذف خودکار کانفیگ‌های تکراری برای سرعت بیشتر
- ذخیره‌ی آخرین کانفیگ سالم؛ اجراهای بعدی در حدود ۱۵ ثانیه انجام می‌شوند
- تنظیم NekoRay طوری که **هر بار باز شدن برنامه، خودکار به همان کانفیگ وصل شود**
- تأیید اتصال با تست پورت SOCKS خودِ NekoRay
- حالت‌های `system_proxy` (بدون نیاز به Administrator) و `vpn` (TUN)
- فقط با کتابخانه‌های استاندارد پایتون؛ **نیازی به `pip install` نیست**

## راه‌اندازی

1. **پایتون را نصب کنید** (ترجیحاً از python.org) و مطمئن شوید در ترمینال کار می‌کند:

   ```powershell
   python --version
   ```

2. **NekoRay را دانلود و استخراج کنید** (مثلاً در همان مسیر پیش‌فرض).

3. **یک بار NekoRay را باز کنید** تا پوشه‌های `config`، `config/profiles` و `config/groups` ساخته شوند، سپس آن را ببندید.

4. فایل‌های این پروژه را در هر مسیری که راحت‌اید قرار دهید.

5. اگر مسیر NekoRay متفاوت از پیش‌فرض است، یکی از این دو کار را انجام دهید:

   ```powershell
   # روش ۱: هنگام اجرا
   python nekoray_autoconnect.py --dir "D:\path\to\nekoray"

   # روش ۲: متغیر محیطی
   set NEKORAY_DIR=D:\path\to\nekoray
   ```

## گزینه‌های خط فرمان

| گزینه | پیش‌فرض | توضیح |
|---|---|---|
| `--dir PATH` | مسیر بالا | پوشه‌ی نصب NekoRay |
| `--mode system_proxy\|vpn\|none` | `system_proxy` | حالت اتصال NekoRay |
| `--workers N` | `16` | تعداد تست هم‌زمان |
| `--timeout N` | `7` | مهلت هر تست به ثانیه |
| `--test-url URL` | `https://www.gstatic.com/generate_204` | آدرس تست اینترنت |
| `--max N` | `0` (همه) | حداکثر تعداد کانفیگ برای تست در هر دور |
| `--no-launch` | — | فقط کانفیگ سالم را پیدا و ذخیره کن؛ NekoRay را اجرا نکن |
| `--retest` | — | کش آخرین کانفیگ سالم را نادیده بگیر و از اول بگرد |
| `--verbose` | — | نتیجه‌ی هر تست را نمایش بده |

مثال‌ها:

```powershell
# حالت TUN/VPN (ممکن است Administrator لازم باشد)
python nekoray_autoconnect.py --mode vpn

# تست سریع‌تر با تعداد بیشتر
python nekoray_autoconnect.py --workers 20 --timeout 6

# فقط پیدا کردن کانفیگ سالم، بدون باز کردن NekoRay
python nekoray_autoconnect.py --no-launch

# نادیده گرفتن کش و جستجوی کامل
python nekoray_autoconnect.py --retest
```

## نحوه‌ی کار

1. اگر NekoRay در حال اجرا باشد، بسته می‌شود تا فایل‌های تنظیمات قابل تغییر باشند.
2. پروفایل‌های موجود در `config/profiles/*.json` خوانده می‌شوند و به کانفیگ استاندارد sing-box تبدیل می‌شوند.
3. کانفیگ‌های تکراری حذف می‌شوند و کانفیگ‌های غیرقابل‌پشتیبانی (مثل ترنسپورت `xhttp` یا `httpupgrade`) کنار گذاشته می‌شوند.
4. برای هر کانفیگ، هسته‌ی `nekobox_core.exe` که همراه خود NekoRay است روی یک پورت موقت اجرا می‌شود.
5. از داخل همان کانفیگ یک درخواست HTTPS به آدرس تست زده می‌شود؛ اگر پاسخ سالم برگشت، کانفیگ «سالم» است.
6. اولین کانفیگ سالم انتخاب و در `config/groups/nekoray.json` ذخیره می‌شود:
   - `remember_enable = true`
   - `remember_id = شناسه‌ی کانفیگ`
   - `spmode2 = ["system_proxy"]` (یا `["vpn"]`)
7. NekoRay اجرا می‌شود و اسکریپت با تست پورت SOCKS آن (`2080` به‌صورت پیش‌فرض) مطمئن می‌شود اتصال واقعاً برقرار شده است. اگر نشد، کانفیگ سالم بعدی را امتحان می‌کند.

به دلیل تنظیم `remember_enable`، **از این به بعد هر بار که خود NekoRay را باز کنید، خودکار به آخرین کانفیگ سالم وصل می‌شود**.

## فایل‌های وضعیت و بکاپ

- `config/nekoray_autoconnect.json` — کش آخرین کانفیگ سالم (برای اجرای سریع دفعات بعد)
- `config/groups/nekoray.json.bak-autoconnect` — بکاپ تنظیمات اصلی NekoRay (فقط اولین بار ساخته می‌شود)

اگر خواستید به حالت قبل برگردید:

1. NekoRay را ببندید.
2. فایل `config/groups/nekoray.json.bak-autoconnect` را روی `config/groups/nekoray.json` کپی کنید.
3. یا به‌سادگی در `config/groups/nekoray.json` مقدار `remember_enable` را `false` کنید.

## عیب‌یابی

**«NekoRay پیدا نشد»**
- مسیر را با `--dir` درست مشخص کنید.
- مطمئن شوید `nekoray.exe` و `nekobox_core.exe` داخل همان پوشه هستند.

**«هیچ کانفیگ سالمی پیدا نشد»**
- در NekoRay سابسکریپشن‌ها را به‌روزرسانی کنید.
- با `--retest` دوباره تلاش کنید.
- مهلت تست را کمی بیشتر کنید: `--timeout 10`.
- ممکن است در آن لحظه اینترنت یا سرورها مشکل داشته باشند.

**«NekoRay وصل نشد»**
- فایروال یا آنتی‌ویروس را بررسی کنید.
- مطمئن شوید پورت‌های `2080` و `2081` توسط برنامه‌ی دیگری اشغال نشده‌اند.
- در حالت `vpn` ممکن است NekoRay به دسترسی Administrator نیاز داشته باشد؛ ترمینال را Run as administrator اجرا کنید.

**اولین اجرا طولانی است**
- طبیعی است؛ حدود ۴۰۰۰ کانفیگ یکتا تست می‌شود. اجراهای بعدی از کش استفاده می‌کنند و سریع‌اند.

**پنجره‌ی NekoRay بسته می‌شود**
- اگر نسخه‌ی دیگری از NekoRay باز باشد، اسکریپت ابتدا آن را می‌بندد. اگر برنامه‌ی دیگری فایل‌های NekoRay را قفل کرده باشد، ممکن است اجرا نشود.

## امنیت و حریم خصوصی

- کانفیگ‌های NekoRay حاوی رمز، UUID و اطلاعات سرورهای شما هستند و **نباید در گیت‌هاب منتشر شوند**. این پروژه فقط شامل کد و مستندات است.
- اسکریپت هیچ اطلاعاتی را به سرور شخص ثالثی ارسال نمی‌کند؛ تنها اتصال‌ها همان اتصال به سرورهای کانفیگ‌های خود شما و درخواست تست به `gstatic.com` است.
- تست‌ها با گواهی TLS معتبر انجام می‌شوند تا اتصال واقعی و سالم تأیید شود.
